# Ejemplo de Maquetación con Flex

## Descripción del Proyecto
Este proyecto es un ejemplo de maquetación web de una galería de imagenes utilizando CSS Flexbox. Fue desarrollado como parte del curso de Diseños de Interfaces Web para mostrar cómo estructurar y estilizar una galería de imagenes.

## Contenido de la Publicación
- **Estructura del HTML:** Organización de etiquetas semánticas como `header`, `aside`, `main`, `section`, `article`, y `footer`.
- **CSS Flexbox:** Implementación de diseño flexible para acomodar contenido de manera responsiva.
- **Recursos Multimedia:** Uso de imágenes y fuentes externas.

## Desarrollo del Proyecto
El proyecto incluye:
- Una cabecera con un título y subtítulo.
- Un menú de navegación ubicado en el `aside`.
- Un contenido principal dividido en varias secciones y artículos, incluyendo texto y medios gráficos para formar la galeria de imagenes.
- Un pie de página con información adicional, contacto y enlaces a redes sociales.
